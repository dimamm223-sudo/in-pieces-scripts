# In Pieces — C# Unity Scripts

Скрипты для короткой инди-хоррор игры с элементами головоломки и физического взаимодействия. 
Саму игру можно скачать на Itch.io: [Ссылка на твой Itch]

### Реализованные механики в коде:
* **PhysicsPickup.cs** — механика подбора, удержания и сглаживания инерции физических объектов (Rigidbody) с динамическим изменением UI-прицела. Также обрабатывает рейкаст взаимодействия с кнопками на сцене.
* **MonsterAI.cs** — искусственный интеллект противника на базе Unity NavMeshAgent с логикой обнаружения игрока по радиусу (слух/зрение).
* **MonsterAttack.cs** — триггер атаки монстра, вызывающий UI-скример, 2D-звук и жесткое закрытие приложения (Application.Quit) для создания эффекта крипипасты.
* **DoorController.cs & FinalDoor.cs** — логика сбора квестовых предметов, интеграция с TextMeshPro и система автосохранений чекпоинтов через PlayerPrefs между разными сценами.
